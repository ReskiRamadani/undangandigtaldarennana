UNDANGAN DIGITAL DAREN & NANA

1. Buka folder ini di VS Code.
2. Buka index.html.
3. Klik kanan index.html -> Open with Live Server (jika ekstensi Live Server sudah terpasang), atau buka index.html langsung di browser.
4. Untuk mengganti foto, nanti masukkan foto ke folder images lalu ubah bagian galeri di index.html.
5. Untuk mengganti alamat, edit teks "Alamat lengkap akan ditambahkan kemudian."
6. Untuk Google Maps, ganti href pada tombol "Buka Google Maps".
7. Untuk musik, masukkan file MP3 ke folder project dan isi src pada <audio> di index.html.
